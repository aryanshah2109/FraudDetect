How It Works

        
End-to-end ML pipeline from raw data to production inference

      

      

        

          
01

          

            
Data Ingestion

            
1.27M transactions with extreme class imbalance (0.1% fraud). DVC-versioned raw data pipeline.

          

        

        
→

        

          
02

          

            
Feature Engineering

            
Balance error features, one-hot encoding, StandardScaler. Stratified 80/20 split to maintain class distribution.

          

        

        
→

        

          
03

          

            
XGBoost + Optuna

            
Bayesian hyperparameter search. scale_pos_weight=7.45 to handle imbalance. CUDA-accelerated training.

          

        

        
→

        

          
04

          

            
Threshold Optimization

            
Precision ≥65% constraint. Maximize recall within constraint. Result: 99.76% recall, PR-AUC 98.77%.

          

        

        
→

        

          
05

          

            
FastAPI Serving

            
Singleton model loading. Pydantic validation. Sub-100ms inference. Deployed on Render.
